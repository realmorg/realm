REALM v2: components are single `<custom-element>` tags holding a `<script>`, `<style>` and markup, assembled at runtime without a compiler. Adds `defineProps` with a typed prop builder, `useState`, `observe`, native value slots, `_` attribute bindings, native `on<event>` handlers for custom events, attribute-driven fetching, a rewritten `<import-element>`, and `defineStore`. See the migration guide for v1 changes.
