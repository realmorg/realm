The Remix Icon set (`ri`) now comes from Remix Icon 4.8.0, the last release under the Apache 2.0 licence. Later releases use the Remix Icon License, which forbids redistributing the icons in another icon library. The 41 icons added after 4.8.0 (for example `cursor-ai-line`, `grok-ai-line` and `cookie-line`) are no longer in the set; every other name is unchanged.
