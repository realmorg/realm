## What is coming

The first release focuses on what free libraries rarely ship, and on the pages most apps need. Items ship one by one and appear in your download as soon as they are ready.

| Kind | Planned for the first release |
| --- | --- |
| Components | A date range picker with presets, and a data grid that scrolls through 100,000 rows with sorting, filtering, column resizing and keyboard navigation |
| Blocks | Stat cards with charts, data tables with filters, settings sections, billing and team pages, activity feeds, empty states, sign-in and sign-up forms, heroes, feature grids, pricing tables, testimonials, FAQs and footers |
| Layouts | Whole pages for a dashboard, settings, sign-in and a landing page |
| Themes | Three colour themes, each with light and dark modes |

Every item follows the same rules as REALM UI: one `<custom-element>` per component, native HTML first, theme tokens for every size and colour, keyboard and screen reader support, and tests in Chromium, Firefox and WebKit.

## How you get it

- **A download.** A zip of every item, from your Polar customer portal. Copy the files into your site and load them with `<import-element>`.
- **An npm package.** `@realmorg/pro` from GitHub Packages, for projects with a build step.
- **The source.** Read access to the private `realmorg/realm-pro` repository on GitHub.

## What stays free

REALM, REALM UI, Unicons, the Vite plugin, the docs and the agent skill stay free and open source under the MIT licence. Pro adds finished pieces on top. It never locks a feature that REALM has today.
