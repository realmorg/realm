## What is coming

The first release has 250 items: what free libraries rarely ship, and the pages most apps need. Items ship in batches and appear in your download as soon as they are ready.

| Kind | In the first release |
| --- | --- |
| Components | A data grid that scrolls through 100,000 rows with sorting, filtering, column resizing, pinning, selection and editing; a date range picker with presets; a flipbook with a 3D page turn |
| Blocks | About 190: stats, data tables with filters and bulk actions, settings, billing, team, activity feeds, notifications, onboarding, empty states, sign-in, sign-up, password reset, one-time codes, heroes, features, pricing, testimonials, FAQs, headers, footers, logo clouds, calls to action and cookie consent |
| Layouts | 30 whole pages: dashboards, settings, authentication, landing pages and docs |
| Themes | 28 colour themes, each with light and dark modes and checked contrast |

After launch, the 1.x series adds a scheduler, an advanced charts pack, a kanban board, a gallery, a product tour, a rich text editor, and e-commerce, inbox and file browser blocks.

Every item follows the same rules as REALM UI: one `<custom-element>` per component, native HTML first, theme tokens for every size and colour, keyboard and screen reader support, and tests in Chromium, Firefox and WebKit.

## How you get it

- **A download with REALM Pro Studio.** A zip of every item, from your Polar customer portal. Run `bun run studio` in it to browse, search and preview every item at desktop and phone widths in light or dark mode, try your colours, copy code, and add items to your project. It works offline: REALM and REALM UI are inside.
- **An npm package.** `@realmorg/pro` from GitHub Packages, for projects with a build step.
- **The source.** Read access to the private `realmorg/realm-pro` repository on GitHub.

## What stays free

REALM, REALM UI, Unicons, the Vite plugin, the docs and the agent skill stay free and open source under the MIT licence. Pro adds finished pieces on top. It never locks a feature that REALM has today.
